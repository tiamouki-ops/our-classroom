그때 우리 교실 — 맵 에디터 V1.0

1) map-editor.html을 Chrome에서 더블클릭해서 여세요. 인터넷 연결 없이 편집할 수 있습니다.
2) 건물/나무를 클릭하고 마우스로 드래그하세요. 빈 공간을 드래그하면 지도가 이동합니다.
3) 벤치·나무·조형물을 추가할 수 있습니다. 건물은 고유 이름과 입장 기능을 보호하기 위해 복제/삭제를 제한했습니다.
4) 위쪽의 [village-map.json 저장]을 눌러 다운로드하세요.
5) index-map-enabled.html을 index.html로 이름 바꾸고, village-map.json 파일과 함께 Cloudflare 정적 에셋으로 배포하세요.
6) 게임은 기존 마을/우리집/학교/복도/교실/NPC 기능을 유지하며 마을 건물과 나무 배치를 JSON에서 읽습니다.
7) 웹서버에서 JSON을 불러오지 못하면 기본 맵으로 작동합니다. 로컬 파일(file://) 테스트에서는 JSON fetch가 차단될 수 있습니다.
8) 현재 Cloudflare Workers 수동 업로드 환경에서는 JSON까지 함께 배포해야 변경된 배치가 반영됩니다.

중요: 현재 정상작동 중인 V0.4 index.html을 반드시 먼저 백업하세요. 이 파일을 그대로 덮어쓰지 마세요.
주의: 이 맵 편집기는 현재 마을 외부 맵만 수정합니다. 교실/집 내부 맵은 추후 확장 대상입니다.
